DBMS CONCEPT LAB

Learn the storage model

Understand the concepts before experimenting with the simulator.

01

File Organization

File organization describes how records are arranged and stored in secondary storage.

02

Heap Files

A heap file does not maintain records in key order. New records are typically appended.

03

Sequential Files

A sequential file maintains records according to a selected ordering primary key.

04

Disk Blocks

Databases transfer data between secondary storage and memory in blocks or pages. FILEFORGE models this visually.

05

Searching

Searching can require examining multiple records. The simulator counts comparisons and simulated block accesses.

06

Insertion

Heap insertion appends a record in O(1), while sequential organization must maintain key ordering in O(N).

07

Deletion

Deletion requires locating the record and updating the file representation via tombstones or compaction.

08

Block Capacity

Changing block capacity lets you observe how the number of storage blocks and internal fragmentation change.

09

Real Applications

Different storage organizations are selected depending on workloads such as high-frequency insertion or ordered access.
