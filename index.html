DBMS CONCEPT LAB

Learn the storage model

Understand the concepts before experimenting with the simulator.

01

File Organization

File organization describes how records are arranged and stored in secondary storage.

02

Heap Files

A heap file does not maintain records in a particular key order. New records can typically be appended.

03

Sequential Files

A sequential file maintains records according to a selected ordering key.

04

Disk Blocks

Databases transfer data between secondary storage and memory in blocks or pages. FILEFORGE models this behavior visually.

05

Searching

Searching can require examining multiple records. The simulator counts comparisons and simulated block accesses.

06

Insertion

Heap insertion can append a record, while sequential organization may need to maintain key ordering.

07

Deletion

Deletion requires locating the record and updating the file representation.

08

Block Capacity

Changing block capacity lets you observe how the number of storage blocks changes for the same dataset.

09

Real Applications

Different storage organizations can be selected depending on workloads such as frequent insertion or ordered access.
